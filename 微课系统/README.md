# 学思践悟 · AI 多模态实训系统（新样式版）

> 编辑设计风格前端 + 双运行模式：**快速预览模式**（零依赖，给评委看）与**完整模式**（真实本地模型推理）。

## 一、这一版有什么不同

| 能力 | 说明 |
|---|---|
| **全新视觉语言** | Editorial 编辑设计风格：衬线大标题（Playfair Display）+ 等宽技术标签（Space Mono）+ 森林绿主色 `#3d7068`；固定 40px 方格底纹与 25/50/75% 垂直导引线 |

- 带标点、分段的完整教学文稿（2298 字，20 个自然段）
- 26 段带时间戳的分析时间轴（含背对/手势标记）
- 6 个维度的评分卡
- 教态数据与预警（背对占比、手势频次、左右均衡度等）
- 2 条真实检索到的课程标准依据

这节课的内容主线是：餐厅经理（旧知）→ 厨师角色（新知需求）→ SortValues 排序思想 → 多列排序 → Head/Tail 函数 → 消费者视角（预告）。

> 课程内容数据位于 `frontend/app/data/previewData.ts`，可随时替换为其他课程材料。

### 4.2 选项式苏格拉底对话

进入 `/chat` 后自动开始，共 **4 轮**，全部围绕这节课的真实教学细节展开：

| 轮次 | 聚焦主题 |
|---|---|
| 01 | 导入环节 —— 学生给出「菜品受欢迎＋出餐速度」两条线索，教师为何只顺着一条走 |
| 02 | 提问价值 —— 「销量相同怎么排」这个问题的含金量与抽象门槛 |
| 03 | 错误资源 —— 用第一组的错误代码做对比，如何措辞才不打击学生 |
| 04 | 改进方案 —— 明天再上这节课会改哪里 |

每轮给出 3 个选项（`A / B / C`），点击后：

1. 该选项文本以「你」的身份进入对话
2. AI 回复逐段流式输出（带打字与停顿节奏）
3. 进入下一轮，AI 先抛出下一轮的引导问题

> AI 的追问会引用这节课的真实细节（如「二人小组 + 讨论区计时 5 分钟/6 分钟」「Excel 排序窗口的类比」「学生说出『覆盖』这个关键词」），使演示具有真实感与说服力。

## 五、Whisper 后处理：同音纠错 + 标点还原

### 5.1 为什么需要

Whisper 的中文输出同时存在两类问题：

**问题一：缺少标点，或只有半角标点**

```
各位同学好,今天我们来学习信息技术的基本概念,首先什么是信息?信息是客观世界各种事物的特征的反应
```

**问题二：专业术语被听成同音别字**

| 识别成 | 应为 | 识别成 | 应为 |
|---|---|---|---|
| 无时无刻**不再** | 无时无刻**不在** | **初**餐速度 | **出**餐速度 |
| **带/代**排序 | **待**排序 | 降**续**排序 | 降**序**排序 |
| **生讯**排序 | **升**序排序 | **复改** | **覆盖** |
| **永续**排序 | **有序**排序 | 销**售** | 销**量** |

### 5.2 实现方式：纯本地规则引擎，零 API 消耗

`backend/core/punctuation.py` 分两个独立阶段处理：

**阶段 A — 同音错字纠正（白名单）**

采用「保守白名单」策略：只有**整词精确匹配**才替换，绝不做模糊匹配。表格按错误词长度倒序，保证长词优先（先匹配 `无时无刻不再` 再匹配可能的短词）。部分词条带**上下文保护**，例如 `销售额` 不会被误改成 `销量额`。

**阶段 B — 标点还原**

1. **标点规范化** —— 半角 `,` `?` `!` `;` `:` `.` → 全角 `，` `？` `！` `；` `：` `。`；合并重复标点；清理标点周围空格
2. **句子切分** —— 优先尊重 Whisper 已有的句末标点，其次依据句末语气词（吗/呢/吧…）与句首起始词（首先/其次/所以/但是…）
3. **小句切分** —— 在连词处插入逗号；句内已有标点时保持既有标点不变，只为过长片段补逗号
4. **收尾清理** —— 消除 `，。` `？？` 等跨阶段拼接产生的非法标点组合

### 5.3 关键设计：词语边界保护

引擎内置「危险断点」判定，切分点必须通过校验，否则一律不断：

- 双字词表（`接下` `相同` `同时` `菜肴` …）
- 构词字结尾黑名单（`相` `一` `不` `没` …）
- 残句回收：过短的孤立句并回上一句

实测效果（2298 字真实课堂文稿）：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 词中被切断 | 3 处 | **0 处** |
| 非法标点组合 | 16 处 | **0 处** |
| 残留过短句 | 8 处 | 1 处 |

### 5.4 保真性保证

纠错阶段**只按白名单替换已知音近错误**，标点阶段**只加标点、不改字词**。可用字符数比对验证：

```
原文去标点 2167 字  ==  输出去标点（还原纠错后）2167 字   ✓
```

### 5.5 纠错透明化

后端会返回本次实际修正的词对，前端可展示「改了什么」，避免纠错成为黑盒：

```python
punctuation_restorer.diff_corrections(raw_text, full_text)
# → ['无时无刻不再→无时无刻不在', '初餐→出餐', '代排序→待排序', ...]
```

### 5.6 处理效果

| 输入（Whisper 原始输出） | 输出（纠错 + 标点后） |
|---|---|
| `各位同学好,今天我们来学习信息技术的基本概念,首先什么是信息?` | `各位同学好，今天我们来学习信息技术的基本概念，首先什么是信息？` |
| `得到了DF1代排序的对象` | `得到了DF1待排序的对象` |
| `菜肴风格是进行了永续排序的` | `菜肴风格是进行了有序排序的` |

### 5.7 扩展纠错表

新增纠错词条只需编辑 `backend/core/punctuation.py` 中的 `_HOMOPHONE_FIXES` 字典：

```python
_HOMOPHONE_FIXES: Dict[str, str] = {
    "销售": "销量",
    "代排序": "待排序",
    # 新增词条写在这里即可，无需改动其他代码
}
```

若某词条需要上下文保护（如 `销售额` 不应被改），同步在 `_HOMOPHONE_SKIP_CONTEXT` 中登记例外即可。

## 七、API 配置界面（完整模式）

完整模式下**不需要手工编辑 `backend/.env`**，可直接在页面里填写 API Key。

### 7.1 从哪里进入

| 位置 | 入口 |
|---|---|
| 首页 | 「API 设置」卡片（模式切到 FULL 后自动出现在分析工作台顶部） |
| 对话页 | 右上角 `API 已配置 / 未配置 API` 按钮，点击展开抽屉 |

### 7.2 可以配置什么

- **API Key** —— 输入框默认掩码显示，可点 `SHOW` 切换明文
- **服务地址（Base URL）** —— 提供服务商预设一键填充
- **模型名** —— 带输入建议（datalist）

服务商预设：

| 预设 | 地址 |
|---|---|
| DeepSeek 官方 | `https://api.deepseek.com` |
| DeepSeek 兼容模式 | `https://api.deepseek.com/v1` |
| 阿里云百炼（通义千问） | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` |
| Moonshot（Kimi） | `https://api.moonshot.cn/v1` |
| 本地 Ollama | `http://127.0.0.1:11434/v1` |

### 7.3 三个关键设计

**① 保存后立即生效，无需重启后端**

Agent 不再在启动时缓存客户端，而是每次调用时按 `(api_key, base_url)` 读取配置：

```python
def _get_client(self):
    api_key  = runtime_config.api_key
    base_url = runtime_config.base_url
    cache_key = (api_key, base_url)
    if self._client_cache is not None and self._client_cache_key == cache_key:
        return self._client_cache          # 配置未变 → 复用连接
    self._client_cache = OpenAI(api_key=api_key, base_url=base_url)
    self._client_cache_key = cache_key
    return self._client_cache              # 配置已变 → 自动重建
```

**② 密钥永不回传明文**

状态查询接口只返回掩码：

```
sk-abcdefghijklmnop1234  →  sk-abc••••••1234
```

持久化文件权限为 `0600`，且已加入 `.gitignore`。

**③ 保存前可先测试连通性**

「测试连接」会真实发起一次极小的对话请求（`max_tokens=4`），验证「地址 + 密钥 + 模型名」三者是否真的可用，并把常见错误翻译成可操作的中文提示：

| 底层错误 | 界面提示 |
|---|---|
| 401 / invalid_api_key | API Key 无效或已过期，请检查密钥是否填写正确 |
| 404 / model_not_found | 模型「X」在该服务地址下不存在，请检查模型名 |
| 403 | 该密钥无权访问此模型，或账户余额不足 |
| 429 | 请求过于频繁或额度已用尽，请稍后重试 |
| connect / timeout | 无法连接到 X，请检查服务地址与网络 |
| SSL | SSL 握手失败，请检查服务地址是否正确 |

### 7.4 配置优先级

```
界面填写（runtime_config.json）  >  .env / 环境变量  >  默认值
```

清除界面配置后会回落到 `.env`；两者都没有时，**本地能力（转写 / 姿态分析 / 课标检索）仍然可用**，只有 AI 点评与对话不可用。

## 八、新增/改动的 API

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/v1/models` | 探测模型环境：设备、PyTorch 版本、已装模型、支持列表 |

- `whisper_model` —— 本次使用的精度

## 十一、数据分析缺陷修复记录

在使用真实课堂数据验证时，发现并修复了两个会影响结论可信度的问题。

### 10.1 教态位移指标量纲错误

**问题**：`movement_range` 是对所有采样点累加 `|Δx| / 画面宽度` 得到的**位移路径总长**，会随视频时长无限增长。真实数据中该值高达 `13696.4`。

**影响**：判定站位是否固定的代码是 `movement_val < 0.05`，拿一个动辄上千的累计值去和 `0.05` 比较，**条件永远不成立** —— 也就是说 `is_stiff` 恒为 `False`，"站位灵活"这个结论从来没有真正被计算过。

**修复**：引入按分钟归一化的位移速率。

```python
movement_rate = stats["movement_range"] / total_minutes   # 画面宽度 / 分钟
MOVEMENT_STIFF_RATE = 0.8
is_stiff = (movement_rate < MOVEMENT_STIFF_RATE) and total_seconds > 30
```

**收益**：该指标不再随视频时长漂移，3 分钟与 30 分钟的课可以放在同一把尺子上比较；阈值判定真正生效。前端展示同步标注单位「画面宽/分钟」，原始累计值保留在 `movement_total` 字段供追溯。

### 10.2 课标检索结果重复

**问题**：同一条课程标准在结果中出现两次。

**成因**（两层）：

1. 向量索引中可能存在内容相同的 chunk —— 标准文件被多次加载时，`add_to_index` 只做追加，不去重
2. 相邻 chunk 有 50 字重叠，检索时会被同时命中，返回前未去重

**修复**：两层都补齐去重。

- 入库侧：`add_to_index` 用归一化后的正文建键，重复内容直接跳过；`load_local_standards` 打印库内总数
- 检索侧：多取候选（`k * 3`）后经 `_dedupe` 过滤精确重复项与高度重合的相邻片段，再截取 `k` 条

**验证**：同一文件连续加载两次，库内条数不变（0 新增）；检索返回的 2 条为互不相同的课标。

## 十二、常见问题

**Q：macOS 双击 `.command` 提示「无法打开，因为它来自身份不明的开发者」？**
右键点击该文件 → 选择「打开」→ 在弹窗中再次点击「打开」即可。
或前往「系统设置 → 隐私与安全性」，在页面下方点击「仍要打开」。

**Q：`./start.sh` 提示 `Permission denied`？**
执行一次授权即可：`chmod +x start.sh 启动学思践悟.command`

**Q：启动后浏览器没有自动打开？**
手动访问终端里显示的地址（默认 <http://localhost:3000>）。
若想禁止自动打开，使用 `NO_OPEN=1 ./start.sh preview`。

**Q：端口 3000 被占用怎么办？**
脚本会自动复用已有服务；如需换端口：`FRONTEND_PORT=4000 ./start.sh preview`

**Q：怎么确认服务是否还在运行？**
`./start.sh stop` 会列出并停止所有服务。也可查看 PID 文件 `.run/*.pid`，
或访问 <http://127.0.0.1:8000/api/v1/models> 检查后端状态。

**Q：预览模式会调用任何模型或网络接口吗？**
不会。全部数据来自 `frontend/app/data/previewData.ts`，对话由本地脚本驱动，不发起任何请求。

**Q：怎么配置 API Key？需要改代码或重启吗？**
不用。完整模式下首页有「API 设置」卡片，对话页右上角也有入口。填好点「保存并生效」即可，**无需重启后端**。建议先点「测试连接」确认可用。

**Q：我用的不是 DeepSeek，可以吗？**
可以。只要服务商兼容 OpenAI 接口，在「服务地址」里选预设或手填 Base URL，再把「模型名」改成对应模型即可（如 `qwen-plus`、`glm-4-plus`）。本地 Ollama 也支持。

**Q：API Key 会被上传或写进代码库吗？**
不会。密钥只保存在本机 `backend/data/runtime_config.json`（权限 `600`），查询接口只返回掩码（`sk-abc••••••1234`），该文件已加入 `.gitignore`。

**Q：完整模式提示「尚未配置 API Key」怎么办？**
在 `backend/.env` 中写入 `DEEPSEEK_API_KEY=sk-xxx` 后重启后端。注意：**本地模型能力（语音转写、姿态分析、课标检索）不受影响**，只有 AI 对话与点评需要 Key。

**Q：模型下载很慢或失败？**
Whisper 权重从 OpenAI 官方源获取。若网络受限，可先选较小的模型（Tiny 75 MB / Base 142 MB），或手动把 `.pt` 权重放入 `~/.cache/whisper/`。

**Q：课标检索会联网吗？**
不会。向量模型已做**离线优先**处理（`HF_HUB_OFFLINE=1`）；若本地无缓存，会自动降级为关键词检索，功能仍然可用，不会阻塞启动。

**Q：如何把演示课程换成真实课程内容？**
编辑 `frontend/app/data/previewData.ts`，替换 `DEMO_COURSE`、`DEMO_TRANSCRIPTION_TEXT`、`DEMO_RESULT` 以及 `DEMO_SCRIPT` 中的对话脚本即可。
